# PeaceCraft III 0.17.0

This release adds one script native and extends the five-minute campaign probe
to every campaign.

- `LeaderboardSetItemLabelColor` sets a leaderboard row's label colour with the
  same row, channel and byte checks as `LeaderboardSetItemValueColor`. RoC
  Human08 called it during its opening and refused before this release.
- The five-minute post-control probe now accepts an interlude's map exit. An
  interlude's skip requests `EndGame` or `ChangeLevel` instead of returning
  player control; the probe prints which exit and the next map. A mission whose
  skip neither returns control nor requests an exit still fails.
- The same probe now starts chapters of campaigns a fresh profile keeps locked
  the way the locked startup probe does. The Human campaign still launches
  through the mission button.

Original assets remain local and are not included in the release or browser demo.
The README screenshots are the 0.16.0 captures.

## Limits

The 0.16.0 limits apply unchanged; see [0.16.0](0.16.0.md). No five-minute sweep
of all campaigns has been run with the new probe yet.
