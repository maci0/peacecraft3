# PeaceCraft III 0.14.0

This release improves minimap sight fidelity, connects Gameplay preferences to
the campaign camera and tooltips, and corrects the single-player escape menu.

- Gameplay mouse/keyboard scrolling and Enhanced Tooltips support Apply, Cancel,
  persistence and their live camera/HUD consumers.
- Escape panels use the selected original executable's modal-root and backdrop
  anchors. The hidden single-player Pause frame still anchors other controls.
- Completed chapter configuration is acknowledged without requesting the map a
  second time, preventing a delayed reload after Quit.
- Shared-vision candidate accounting follows the admitted source table after
  unit removal, preserving exploration history.
- Parser bounds, checked texture/model arithmetic and several allocation-heavy
  paths were improved.

Original assets remain local and are not included in the release or browser demo.
The existing screenshot provenance still describes the 0.13.0 captures.

## Limits

Menu functionality and pixel parity remain incomplete. Save/Load, in-game
Options, Help/Tips and other unfinished routes remain tracked in
[menu acceptance](../menu-acceptance.md). Campaign progression remains open.

The isolated rendered campaign run verifies menu pause/resume, Return, exit
cancellation, restart, Quit, old-session/camera/HUD retirement, frozen exit
capture and a subsequent chapter launch. Its final renderer assertion still
fails for an unsupported CityBuildingSmall PRE2 particle mode. This is not a
fully passing rendering gate or an original-client pixel-parity claim.

The full-frame menu diagnostic remains unsynchronized in world state and ticks.
After the anchor correction it reports 1,001,490 differing pixels of 1,228,800,
with mean absolute channel error 22.320694715711806. Border tiling, dimming, text
and disabled-control differences remain visible.

## Release checks

- Rust game/host suites: 3,846 passed, zero failures, 217 explicit/input-dependent
  ignores; run headless with inaccessible display/audio sinks.
- Native and WASM Clippy: warnings denied, passed.
- Browser unit tests: 104 passed, zero failures, two input-dependent skips.
- Pages allowlist and desktop packaging-helper self-tests: passed.

Windows/macOS executables were not built on this Linux host. The rendered
campaign limitation above remains separate from the passing unit/build checks.
