# PeaceCraft III 0.15.0

This release fills in the in-game Help and Tips pages, opens Options from the
in-game menu, connects the Custom Keys and Unit Responses options, and launches
Credits from the main menu.

- Help shows `UI\HelpStrings.txt` in the default font the selected client image
  defines. Tips shows `UI\TipStrings.txt`: Next and Back wrap, OK closes, and the
  selection survives hiding the menu.
- Options opens from the in-game menu while the campaign stays paused. Cancel or
  Escape returns to the in-game menu and discards unapplied changes.
- Custom Keys applies `CustomKeys.txt` hotkey overrides to command-card buttons,
  and Unit Responses gates unit acknowledgement voices. Both support Apply,
  Cancel and persistence, with defaults read from the selected client.
- Credits launches the edition's credits map named in `UI\MiscUI.txt`.
- Texture Quality's mip and colour-depth policy is read from the executable's
  Options code. The control stays a read-only preview (see Limits).
- Skeleton posing with a repeated bone object id regressed in 0.14.0 and again
  uses the first bone's parent. `pcx-sim` no longer panics looking up unit id 0.
  Menu buttons keep their authored corner size when it fits.
- Developer tooling: a gameplay observation bridge, bounded step driver and
  cross-process gameplay fixture in test-fixture builds; the `tools/jev-harness`
  client that drives them; and exact-RGB diff, mask, overlay and side-by-side
  reports for original-reference comparisons.

Original assets remain local and are not included in the release or browser demo.
The existing screenshot provenance still describes the 0.13.0 captures.

## Limits

Menu functionality and pixel parity remain incomplete; see
[menu acceptance](../menu-acceptance.md). In-game Options has no working OK yet,
and Save/Load remain unfinished. Custom Game discovers and admits maps in code,
but its screen does not list or launch them. Texture Quality's 16-bit choices
have no established storage format and its 32-bit choice already matches the
current renderer, so the popup is preview-only. Subtitles has no consumer.
Campaign progression remains open. No new original-client full-frame comparison
was run for this release.

Windows/macOS executables were not built on this Linux host.

## Correction (0.15.1)

The in-game Options entry above overstated 0.15.0. Its button switched the
route to the front-end Options screen, which stays hidden while a campaign plays,
so no options panel appeared. 0.15.1 disables the button until the in-game
`EscMenuOptionsPanel` is rendered.
