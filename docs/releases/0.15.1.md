# PeaceCraft III 0.15.1

This patch release restores the Windows desktop builds and corrects the in-game
Options entry.

- The `peacecraft3` test binary compiles for Windows again. A test-only campaign
  profile permission check used Unix-only APIs without a platform guard, so both
  Windows desktop-build jobs had failed since 0.14.0.
- The in-game menu's Options button is disabled. In 0.15.0 it switched to the
  front-end Options screen, which stays hidden while a campaign plays, so no
  panel appeared. The original's in-game options panel
  (`UI\FrameDef\UI\EscMenuOptionsPanel.fdf`) is not rendered yet.

Original assets remain local and are not included in the release or browser demo.
The existing screenshot provenance still describes the 0.13.0 captures.

## Limits

The 0.15.0 limits still apply; see [0.15.0](0.15.0.md) and
[menu acceptance](../menu-acceptance.md).

## Release checks

- Rust workspace suites with `pcx-play/test-fixtures`, `peacecraft3/test-fixtures`
  and `pcx-net/session-server`: 5,452 passed, zero failures, 355
  explicit/input-dependent ignores; run headless with a private display and null
  audio.
- The local original-asset escape-menu gate (Legacy 1.29.2.9231; Prologue02, roc)
  passed.
- `x86_64-pc-windows-gnu` check of the `peacecraft3` test binary: passed, and fails
  with the 0.15.0 errors without the fix.
- Native and WASM Clippy: warnings denied, passed. Native and WASM workspace
  builds passed.

Windows/macOS executables were not built on this Linux host.
