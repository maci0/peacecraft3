# PeaceCraft III 0.19.0

This release integrates map observer delivery, retained music playback and
bounded timed-turn diagnostics with source-derived replay queries.

- Initialized map VM observers validate program ownership and preserve callback
  faults through wake, retirement and cleanup paths.
- Music commands retain their execution order through snapshot publication.
  Native playback connects source-derived looping, volume and retained sinks.
- Stationary units with a supported default melee weapon can turn over time.
  Automatic target acquisition ends the timed turn. The runtime refuses
  unsupported activity before changing the turn.
- Current acquisition range reads the source default for supported units.
  Widget life reports the unit's stored life. Static terrain queries use
  the map raster and the terrain policy associated with the selected executable.
- Vendored dependency fixes support Rust 1.100.0. Dedicated build targets and
  build provenance records qualify local dependency reuse.

## Limits

Armed-turn timing remains unqualified. The narrow replay compared the baseline
and timed-turn cases. In both recreation runs, the first attacked event
with the replay’s attacker-role code 2 occurred at 0.525 seconds, between
target reveal and removal. The retained original runs recorded 0.700 and
0.730 seconds respectively.
Both unchanged full control replays stopped at the unsupported
`IsUnitInRange` call.
See the [replay evidence](../re-notes/script-unit-world.md#normal-legacy-campaign-admission-and-replay-getters-2026-11-18).
Acquisition overrides, broader event responses, GUI Counter adoption, full
Save/Load and complete rendered or audible fidelity remain open.

The browser demo supports local asset imports and partial menus. Original game
archives, executable images, fonts, sounds and extracted content stay local.

## Release validation

The fresh Linux workspace run passes 6,118 tests with zero failures and 485
explicit or local-input ignores across 183 test executables. This count excludes
doctests. The JavaScript suite passes 100 tests with two explicit skips, and the
FreeArc decoder checks pass 17 tests. Six map-configuration controller checks
pass separately. Packaging and desktop-format helper self-tests pass.

Strict native workspace all-target Clippy and workspace WASM library Clippy pass
on Rust/Cargo 1.100.0 with warnings denied. The screenshot test passes with its
`test-fixtures` feature, 13 held-clock receipts and matching repeated PNGs.
All five published images were visually inspected. The capture held real,
virtual, fixed, and map clocks during GPU warm-up and readback. See
[capture provenance](../screenshots/provenance.json). Linked local sources,
features, compiler flags and artifacts were recorded for each build stage.

The default-feature Linux executable built successfully. Both Windows jobs
passed in the separate release run. See [desktop validation](../build-desktop.md#validation-status)
for the macOS failures and CI receipts.

The optimized production WASM passes the packaged browser gate locally and on
GitHub Pages. Each run makes 20 code/WASM or local Blob GET requests with zero
page errors, uploads or sockets. Base-only edition restrictions and import/clear
ownership checks pass. All 27 hosted code, WASM and license/source-offer files
match the checked package byte for byte. These browser checks use synthetic
content; original-client visual comparison was outside this release run.
