# PeaceCraft III 0.19.0

This release integrates map observer delivery, retained music playback and
bounded timed-turn diagnostics with source-derived replay queries.

- Initialized map VM observers validate program ownership and preserve callback
  faults through wake, retirement and cleanup paths.
- Music commands retain their execution order through snapshot publication.
  Native playback connects source-derived looping, volume and retained sinks.
- Stationary timed facing admits a bounded default melee-weapon class. Runtime
  transition checks refuse unsupported activity before changing the relation.
- Current acquire range reads a qualified ordinary unit's source default.
  Widget life reads canonical admitted unit life. Static terrain queries use
  the normal campaign factory's selected executable and existing map raster.
- Vendored dependency compatibility fixes support the current stable Rust
  toolchain. Dedicated build targets and linked-source receipts qualify local
  dependency reuse.

The README screenshots were freshly rendered with the 0.19.0 application from
locally supplied Legacy 1.29.2.9231 assets. Capture holds real, virtual, fixed and
map clocks during GPU warm-up and readback.

## Limits

Armed-turn timing remains unqualified. The narrow recreation capture's first
attacked event occurs at 0.525 seconds in both arms, while the retained original
baseline and timed observations occur at 0.700 and 0.730 seconds. The full V9
protocol still refuses `IsUnitInRange`. Acquisition overrides, broader event
responses, GUI Counter adoption, full Save/Load and complete rendered or audible
fidelity remain open.

The browser demo supports local asset imports and partial menus. Original game
archives, executable images, fonts, sounds and extracted content stay local.

explicit or local-input ignores across 183 test executables. This count excludes
doctests. The JavaScript suite passes 100 tests with two explicit skips, and the
FreeArc decoder checks pass 17 tests. Packaging and desktop-format helper
self-tests pass.

Strict native workspace all-target Clippy and workspace WASM library Clippy pass
on Rust/Cargo 1.100.0 with warnings denied. Six map-configuration controller
checks pass separately. The screenshot test passes with its explicit
`test-fixtures` feature, 13 held-clock receipts and matching repeated PNGs.
All five published images were visually inspected. Linked local sources,
features, compiler flags and artifacts were recorded for each build stage.

The default-feature native game executable also builds successfully. Windows
and macOS packaging runs through the existing desktop workflow separately.

The optimized production WASM passes the packaged browser gate locally and on
GitHub Pages. Each run makes 20 code/WASM or local Blob GET requests with zero
page errors, uploads or sockets. Base-only edition restrictions and import/clear
ownership checks pass. All 27 hosted code, WASM and license/source-offer files
match the checked package byte for byte. These browser checks use synthetic
content; original-client visual comparison was outside this release run.
