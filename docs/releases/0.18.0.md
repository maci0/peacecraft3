# PeaceCraft III 0.18.0

This release consolidates scripting, source admission and lifecycle work while
keeping unfinished gameplay paths explicitly unsupported.

- Script strings retain raw bytes through VM storage, callbacks, traces and
  caches. Text consumers decode explicitly. Source-qualified initial-C
  `StringCase` and bounded signed-word `SubString` are connected.
- Leaderboard updates, construction payments and cleanup, pending structure
  upgrades, incomplete technology counts and bounded food accounting preserve
  refusal atomicity and their source-derived relationships.
- Auxiliary client modules are pinned to the selected engine generation outside
  MPQ resolution. Local, ISO and supported stored-installer imports retain
  checked transaction ownership. Regular music volume uses the selected curve
  and backend scaling.
- Explicit native counter startup supports separate Game/Real sleep transport,
  retained budget retries and ordered logical/callback/visual heading phases.
  Generic application startup retains its existing caller-time behavior.
- Continuation components retain VM bytes, RNG streams, live abilities,
  in-memory cache state, AI source bindings and native queue state. These are
  components, not a complete Save/Load feature.

Original assets remain local and are not included in the release or demo.
Superseded drafts and deferred startup work are retained in Git history, with
the accepted defaults restored in the released tree.

## Limits

Normal GUI native-counter adoption remains held. The stationary long-turn
controller, observer bridge and regular-playback controller remain diagnostic
or test-fixture work; default production dispatch refuses unqualified paths.
Moving/paused turning, automatic acquisition and Heal execution, complete
world/application save restoration, audible fidelity and full native tick
parity remain unfinished. Non-C string locales, unsafe substring pointer
domains and several upgrade bonus/refund classes remain explicit refusals.

The latest explicit native-counter Human01 replay reached player control and
then refused a long timed turn. Undead02 refused a long timed turn after
startup. Those failures are not passing campaign horizons. Generic Human01
audio regression gates passed separately before consolidation.

## Release validation

Final combined validation passes 6,405 workspace tests, zero failures and 557
explicit/input-dependent ignores; 35 selected-source/witness gates and 449
additional application executions pass. All 102 JavaScript tests pass. Native
workspace Clippy, native/WASM core and application checks, formatting and library
builds pass with warnings denied. The optimized production WASM passes local
module imports, actual stored-worker extraction and the packaged headless browser
gate. The package contains 27 allowlisted code, WASM and license/source-offer files.

These results do not establish complete native, rendered or audible parity.
Unfinished observer-delivery diagnostics are excluded from runtime qualification;
their production admission remains disabled. Final publication and cleanup are
recorded in TRACKER.md.
Windows/macOS executables are not built on this Linux host; the desktop workflow
provides those target builds independently.
