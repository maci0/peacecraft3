# Optional auxiliary client sources

The client engine and one optional imported module occupy separate slots. Neither
module is a Resolver layer or a map override. The module is not executed.

## Evidence

Static native-code evidence in the locally supplied 1.29.2.9231 main image
(SHA256 `3f2ed0120d80578bf07e4423296dade1adfb959d59a2d20a7584224559570eed`)
connects the regular-volume call at `7c9b51` to an IAT operand. The owning import
descriptor supplies the raw symbol and module leaf at runtime. The selected
sibling bytes have SHA256
`cc142b9d8b5223e2720c6440cb7a124c0a80d2fb04ecf59ad7331dfd6e3cb51f`.
These are qualified source identities, not filename priorities or copied gain
coefficients. Regular gain policy is described in
[regular music volume](script-regular-music-volume.md).

The PE reader walks each descriptor's own terminated thunk list. A preceding
FirstThunk address alone cannot establish ownership. Directory, section, string,
thunk, address and total-work bounds fail explicitly. Ordinal-only demand,
duplicate ownership and unsafe owner leaves refuse.

## Publication

Desktop pinning snapshots only the unique case-insensitive sibling under the
selected canonical installation. Missing input is optional. Invalid paths,
symlinks, duplicate names and changed-file observations refuse the candidate;
ordinary source I/O errors remain an unavailable capability. Queries do not
search the filesystem again.

Browser imports use checked transaction tickets. Local files explicitly
co-select the main and optional module. Direct ISO records require the selected
main's parent and namespace. Stored installer extraction allows one additional
member/block pass in the same selected archive and parent; it has its own bounded
intermediate-work allowance. No installer code runs and no language patch is
applied. Cancelled or retired replies cannot publish a later transaction.

Main, auxiliary and archive generation commit together after successful
hydration. Candidate failure preserves the previous publication. A later import
without auxiliary input clears that slot. Legacy archive append invalidates its
auxiliary attestation. Existing main-image getters retain their original role.

`ClientSources` pins immutable bytes and receipts. Its durable content generation
hashes main identity, the selected archive content multiset, the descriptor/IAT
and raw import names, and missing/failed/present module state plus content hash.
Picker order does not establish priority. Transport paths remain diagnostic;
Resolver roles and explicit priority policy require their own Root binding.
The process import ticket and binding revision are not durable content identity.
No executable bytes or reader closure belong in a saved Root.

Map publication retains the bundle with the exact binding-receipt Arc. Campaign
transitions retain that bundle. Preparation derives regular-volume rules from
this pinned pair and retains errors for the called native. An absent bundle
cannot manufacture this capability from a current global image or another install.

## Verification scope

`client_module_tests` covers relocated nonstock PE imports, own-list termination,
budgets, unsafe/duplicate/ordinal/truncated inputs, portable generation,
missing/duplicate/symlink/refresh native files and explicit selected-image gates.
`client-module-runtime.mjs` exercises production local/direct-ISO/stored staging
through matching generated WASM, including ticket retirement, rollback,
replacement, append invalidation and drop. Its ISO is locally assembled from
supplied members; it does not establish retail ISO acceptance.
`client-module-installer-runtime.mjs` uses the actual worker and codec with local
temporary storage. Older unsupported engine images remain explicit unsupported
policy inputs. These checks do not establish original playback, gain parity,
full Root restore or tick parity.
