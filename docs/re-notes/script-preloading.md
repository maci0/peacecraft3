## Connected behavior

The campaign factory binds the rules to its retained asset resolver and checks
source identity plus the exact six common-script native declarations.
`Preloader` resolves the file and common source through that reader, verifies
common bytes against the admitted map's source, and parses/resolves the file as
JASS. Its own VM runs ordinary helpers, branches, loops and globals. Native calls
use the existing canonical world and numeric policy. Preload globals do not
replace the map's globals. File-specific native declarations and callbacks that
would install this VM's function IDs in the map VM refuse explicitly. Missing
files and requested assets are retained in the public preload report; extraction
or malformed-source failures remain contextual errors.

`Preload` queues actual asset paths. Start, refresh and end calls warm that queue
using bounded resolution. Archive winners are retained in the same resolver and
serve later ordinary asset reads without another source read/decompression.
Cached results retain exact winning provenance and still honor smaller caller
read budgets. Loose filesystem overrides stay live and bypass retention; remount
continues to govern discovery of new paths. No asset bytes enter a committed
cache or report. Queue count, VM recursion/file count, work bytes and retained
cache memory have explicit application ceilings.
