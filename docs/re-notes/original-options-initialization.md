# Original Options value initialization

The qualified Legacy executable, SHA-256
`3f2ed0120d80578bf07e4423296dade1adfb959d59a2d20a7584224559570eed`,
VERSIONINFO 1.29.2.9231, contains a complete Options population routine at
`0x531260..0x531ad4`. Its preference reads connect the named descriptor table
to bound controls. This strengthens the earlier name-based correspondence;
it does not establish the release of adjacent FDF archives or a live first-run
configuration. No original client or preference store was executed or modified.

The checked importer reads fallback bytes from the supplied image. The native
getter can instead return a saved value. These are different inputs, and neither
widget initials nor a nearby descriptor alone establish the effective setting.
See [fallback admission and the current audio consumer](original-options-defaults.md).

## Values, labels and remaining behavior

For the seven quality popups, the returned preference word goes unchanged to
`0x884290`. That body stores the word, forwards it to another delegate, and on
its ordinary title path calls `0x883280`. The latter indexes a pointer array
with that zero-based word before tail-jumping to unread `0x87da40`. The return
then reaches popup title helpers; separate property and sentinel branches can
bypass this path. The native FDF-to-array constructor, nested-menu side effects
and tail target remain unread. Preserving authored MenuItem order is the supported
recreation interpretation; the repeated second MenuItem operand is not a unique
setting ID. Label keys still require the selected localization table.

The slider paths convert the getter word through SSE and a sign-indexed
correction table before calling their value delegate. That correction table and
delegate were not inspected; no percentage divisor, speed curve or gamma
function is inferred. Checkbox paths compare the word with zero and call the
bound-control property delegates; their complete checked/enabled semantics are
separate. The game-port path formats the returned word and calls its text
delegate, without establishing accepted input, network binding or edit limits.
Resolution population and selection have their own
[checked boundary](original-display-modes.md).

The source-only popup adapter prototype selects label keys from checked fallback
bytes and actual parsed FDF order. It refuses missing, malformed, negative,
overflowing and out-of-range values and preserves source identity. A regression
also catches malformed MenuItems being silently dropped by the current widget
parser, shifting subsequent indexes. The corrected prototype rejects the entire
preview if any item is malformed, including items after the selected entry.
Its 15 strict leaf tests, including nine existing FDF tests, pass. It does not mutate applied
or draft settings, enable controls, or change renderer quality, and has not been
installed in the app. Showing an unconsumed fallback as a current setting would
misrepresent runtime state.

Native music/effects already have real consumers. Remaining settings require
their input, renderer, audio, network or gameplay owner before activation. These
observed joins remove uncertainty about their source keys; they do not supply
those missing behaviors. Internal recreation implementations may differ from
the original, while authored values and observable behavior must be preserved.

## Evidence and limits

The bounded static inspection is retained in
`.scratch/options-source-default-presentation-20261016/`. Three initialized code
windows total 11,264 bytes; directly inspected control-name windows total
1,441 bytes. Full source identity is unchanged. Population and popup-store CFGs
close; the array helper ends at its explicitly unread tail target. Independent
instruction-decoder checks are retained. No code
bytes or original fallback table are distributed. Earlier stale-artifact and
compile failures remain failures; the later coherent strict compile and tests
are recorded separately. This is native-code and synthetic-parser evidence,
not rendered Options, original saved-state or complete settings acceptance.
