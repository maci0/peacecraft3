# Mirror Image admission and observed cast

The selected Legacy client operand reader is optional hero-rule admission.
Ranked gameplay data comes from the admitted ability tables and map overlays;
namespace resolution uses the existing campaign recipe, shared with presentation.
The explicit local gate compares the resolved source cell and provenance rather
than assuming an unprefixed table or copying an observed mana cost.

The bounded native reader joins ability registration/class getters, constructor
vtable, scheduled completion event and finalizer. It derives the image cap,
secondary random channel and circle operand, and joins clone creation mode to
the field/bit queried by registered `IsUnitIllusion`. Relocated synthetic
fixtures vary those relationships. A selected-client parser gate establishes
admission, independently of runtime observations.

Stopped original cast Arm A produced one distinct positive illusion, two summon
callbacks and one null summoned/trigger identity. The original collector's
callback-count assumption refused and is preserved with the raw records. CHANNEL
and CAST callbacks occurred inside the public order call; EFFECT then ENDCAST
preceded separation, with the mana debit visible at ENDCAST. Positive SUMMON
observed the caster hidden; later readback saw it revealed. No FINISH callback
was observed. The image retained ability ranks and effective life/mana, but
reported false HERO/SUMMONED and zero hero level/XP/attribute queries. This does
not mean `GetUnitLevel` is zero: Arm B reported the authored unit level five.
The inverted invulnerability getter is documented in
`ability-cancellation-orders.md`.

Stopped Arm B retained the first positive image despite the later null callback,
made it hostile, killed it through public damage, then killed an ordinary-unit
positive control. Image XP delta was zero and control delta forty. This qualifies
victim exclusion for the measured Mirror class; it is not a universal XP or
recipient experiment. Raw records, stopped-run receipt and failed Arm A collector
remain local and ignored.

separation, creation and expiry. CHANNEL/CAST use the existing synchronous event

arena owns the image; no hero progression, food or guard enrollment is added.

publication. Attributes used by regeneration remain distinct from public hero

source cooldown and lifetime use existing deadline/expiry machinery.

secondary stream supplies the real circle slot; primary randomness is untouched.
